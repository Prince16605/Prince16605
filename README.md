# 💻 Featured Projects

### 1. 🚀 Jenkins Automatic Website Deployment

A Jenkins CI/CD project that deploys a static website to an AWS EC2 Ubuntu server, with Nginx serving the deployed files. The documented pipeline includes Checkout, Validate, Deploy, and Verify stages.

**Technologies:** Jenkins • AWS EC2 • Ubuntu • Nginx • GitHub • Shell

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github)](https://github.com/Prince16605/jenkins-automatic-website-deployment)

### 2. 🐳 Multi-Node CI/CD Automation & Docker Deployment Platform

A multi-node DevOps setup using separate Development, Jenkins Controller, and Agent EC2 instances. Demonstrates GitHub integration, Jenkins agent execution, and Docker-based application builds.

**Technologies:** AWS EC2 • Jenkins • Docker • Ubuntu • Git

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github)](https://github.com/Prince16605/Multi-Node-CI-CD-Automation-Docker-Deployment-Platform)

### 3. ❤️ Auto-Healing Linux Services

A Linux reliability project that checks Nginx health on EC2 instances and attempts automatic service recovery using Bash scripts, systemd services and timers, with Ansible ad-hoc commands for remote administration.

**Technologies:** AWS EC2 • Linux • Bash • Ansible • systemd • Nginx

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github)](https://github.com/Prince16605/auto-healing-linux-services)

### 4. ⚙️ Ansible Web Server Automation

Automates web server configuration and website deployment across managed hosts using Ansible Playbooks, reusable Roles, Tasks, Handlers, Variables, and SSH.

**Technologies:** Ansible • Linux • YAML • SSH • Automation

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github)](https://github.com/Prince16605/ansible-webserver-automation)

### 5. 🎟️ AWS Ticket Booking Platform

A ticket booking web application documented with an AWS architecture using Application Load Balancer, Auto Scaling, EC2, RDS MySQL, S3, Lambda, CloudWatch, SNS, and VPC components.

**Technologies:** AWS • EC2 • ALB • Auto Scaling • RDS MySQL • S3 • Lambda

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github)](https://github.com/Prince16605/aws-ticket-booking-platform)

### 6. 🏥 MediCare Plus – Hospital Appointment Booking

A web-based hospital appointment booking application. Patients can view doctors and book appointments. The project documents AWS deployment architecture with RDS MySQL, S3, EC2, Load Balancer, Auto Scaling, CloudWatch, and SNS.

**Technologies:** PHP • MySQL • AWS • EC2 • RDS • S3 • CloudWatch

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github)](https://github.com/Prince16605/Medicare-plus-hospital-booking)
