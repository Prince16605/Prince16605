I enjoy building, automating, and documenting cloud infrastructure and deployment workflows. My hands-on practice focuses on AWS services, Linux administration, CI/CD pipelines, containerization, and infrastructure automation.

- ☁️ Building and exploring AWS cloud environments.
- 🔁 Creating CI/CD workflows with Jenkins, Git, and GitHub.
- 🐳 Practicing containerization and multi-node deployments with Docker.
- ⚙️ Automating server configuration and operations with Ansible and Bash.
- 🧱 Learning and applying Infrastructure as Code with Terraform.
- 📈 Improving my skills in monitoring, reliability, and production troubleshooting.

# What I Do

**Cloud Infrastructure**  
Build and explore AWS environments using services such as EC2, S3, IAM, VPC, RDS, and Route 53, with attention to access control and network fundamentals.

**CI/CD & Deployment Automation**  
Create Jenkins workflows that connect GitHub source changes to automated build and deployment steps, including deployments to AWS EC2.

**Containers & Infrastructure Automation**  
Work with Docker, multi-node deployment patterns, Ansible playbooks, Bash scripts, and Linux service management to reduce repetitive operations.

**Linux & Reliability**  
Practice shell scripting, systemd service management, log analysis, troubleshooting, and automated service recovery.
