# Hi, I'm Prince Vaghasiya 👋

### Cloud & DevOps Enthusiast \| AWS \| Linux \| Docker \| Jenkins \| Terraform

I enjoy building, automating, and documenting cloud infrastructure and
deployment workflows. My hands-on practice focuses on AWS services,
Linux administration, CI/CD pipelines, containerization, and
infrastructure automation.

-   ☁️ Building and exploring AWS cloud environments.
-   🔁 Creating CI/CD workflows with Jenkins, Git, and GitHub.
-   🐳 Practicing containerization and multi-node deployments with
    Docker.
-   ⚙️ Automating server configuration and operations with Ansible and
    Bash.
-   🧱 Learning and applying Infrastructure as Code with Terraform.
-   📈 Improving my skills in monitoring, reliability, and production
    troubleshooting.

------------------------------------------------------------------------

# What I Do

**Cloud Infrastructure**\
Build and explore AWS environments using services such as EC2, S3, IAM,
VPC, RDS, and Route 53, with attention to access control and network
fundamentals.

**CI/CD & Deployment Automation**\
Create Jenkins workflows that connect GitHub source changes to automated
build and deployment steps, including deployments to AWS EC2.

**Containers & Infrastructure Automation**\
Work with Docker, multi-node deployment patterns, Ansible playbooks,
Bash scripts, and Linux service management to reduce repetitive
operations.

**Linux & Reliability**\
Practice shell scripting, systemd service management, log analysis,
troubleshooting, and automated service recovery.

# Featured Projects

### 🚀 Jenkins Automatic Website Deployment

A Jenkins CI/CD project that deploys a static website to an AWS EC2
Ubuntu server, with Nginx serving the deployed files. The documented
workflow includes checkout, validation, deployment, and verification
stages.

`Jenkins` `AWS EC2` `Ubuntu` `Nginx` `GitHub` `Shell`

[![Repository](https://img.shields.io/badge/Repository-View_Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Prince16605/jenkins-automatic-website-deployment)

### 🐳 Multi-Node CI/CD Automation & Docker Deployment

A hands-on multi-node setup using separate development, Jenkins
controller, and agent EC2 instances. The project demonstrates GitHub
source control, Jenkins agent execution, and Docker-based application
builds.

`AWS EC2` `Jenkins` `Docker` `Ubuntu` `Git`

[![Repository](https://img.shields.io/badge/Repository-View_Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Prince16605/Multi-Node-CI-CD-Automation-Docker-Deployment-Platform)

### ❤️ Auto-Healing Linux Services

A Linux reliability lab that checks Nginx health on EC2 instances and
attempts service recovery using Bash scripts, systemd services and
timers, with Ansible ad-hoc commands for remote administration.

`AWS EC2` `Linux` `Bash` `Ansible` `systemd` `Nginx`

[![Repository](https://img.shields.io/badge/Repository-View_Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Prince16605/auto-healing-linux-services)

### ⚙️ Ansible Web Server Automation

Automates web server configuration and website deployment across managed
hosts using Ansible playbooks, roles, tasks, handlers, variables, and
SSH.

`Ansible` `Linux` `YAML` `SSH` `Automation`

[![Repository](https://img.shields.io/badge/Repository-View_Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Prince16605/ansible-webserver-automation)

### 🎟️ AWS Ticket Booking Platform

A ticket booking web application project documented with an AWS
architecture using an Application Load Balancer, Auto Scaling, EC2, RDS
MySQL, S3, Lambda, CloudWatch, SNS, and VPC components.

`AWS` `EC2` `ALB` `Auto Scaling` `RDS MySQL` `S3` `CloudWatch`

[![Repository](https://img.shields.io/badge/Repository-View_Code-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Prince16605/aws-ticket-booking-platform)

### 🏥 MediCare Plus --- Hospital Appointment Booking

A web-based hospital appointment booking application documented with AWS
deployment architecture. The project describes appointment booking,
Amazon RDS MySQL storage, S3 image storage, load balancing, Auto
Scaling, CloudWatch, and SNS.

`PHP` `MySQL` `AWS` `EC2` `RDS` `S3` `CloudWatch`
